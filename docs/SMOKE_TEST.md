# בדיקת עשן לחדר השיעור

שני דפדפנים על אותו שיעור: המורה בחלון רגיל, התלמיד בחלון פרטי. חוזרים על חמשת הצעדים עבור שלושת סוגי השיעור: שיעור seed קיים, שיעור שהתלמיד קבע, ומפגש שתואם על ידי הצוות.

1. המורה נכנס ל-`/lessons/<id>`. התלמיד נכנס לאותו כתובת בחלון פרטי.
2. אצל התלמיד הצ'אט נפתח. ההודעה «הצ'אט אינו זמין כרגע» לא מופיעה, ובקונסול אין `StreamChat error code 17`.
3. המורה מצייר קו על הלוח. הקו מופיע אצל התלמיד.
4. התלמיד מצייר קו. הקו מופיע אצל המורה.
5. בטרמינל: `npx tsx scripts/check-lesson-channel.ts <lessonId>`. בפלט, `members` כולל את מזהה המורה הנוכחי ואת מזהה התלמיד.

הסקריפט רק קורא מ-Stream. הוא לא יוצר ערוץ ולא משנה חברים.
